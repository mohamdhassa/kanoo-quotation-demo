# Routes and Features

## Public / Session
- `/` — role-aware redirect
- `/login` — authentication
- `/logout` — logout and audit event
- `/health` — hosting health check

## Advisor Functions
- New quotation
- Automatic advisor/date/time recording
- Approved or Rejected status
- Refusal reason
- Full/partial VRN search
- Edit quotation
- Status-history tracking
- Rejected -> Approved recovery tracking

## Manager Dashboard
Filters include date range, advisor, vehicle, status, damage area and service.

KPIs include total quotations, approval rate, quoted value, approved value, rejected value, recovered sales, recovered value and average quote.

Analytics include advisor performance, advisor approval rates, advisor values, status distribution, vehicle types, services, damage areas, refusal reasons, daily time series, monthly trend, hourly activity and weekday activity.

## Daily Advisor Performance
Includes every advisor even when the selected day has zero activity. Reports offers, approved, rejected, approval rate, quoted/approved value, panels and recovered sales.

## Excel
- Dashboard export follows active filters.
- Daily-report export produces the selected day's advisor-performance workbook.

## Administration
Manager can create users, reset passwords, enable/disable users, delete unused users, maintain dropdown lists and review the audit log.
